# This Data Is Perfect! | Estonia e-Residency Fraud Audit

Reproducible audit of a 1-nearest-neighbor classifier used to screen e-Residency applications.

**Flag: `SIGMOID_77`**

The released score of **93.42%** is optimistic because submissions belonging to the same identity are allowed to appear in both the training and test sets. The identity-isolated leave-one-group-out result is **76.66%** (1,511 / 1,971).

## Run

Requires Python 3.10–3.12.

```bash
python -m pip install -r requirements.txt
python project_pipeline.py
python audit.py
python corrected_pipeline.py
```

## Three isolated tests

| Choice | Test | Accuracy |
| --- | --- | ---: |
| Original row-level random split | Shipped pipeline | 93.42% |
| Scaling before train/test separation | Fit scaler on training rows only | 93.67% |
| No class stratification | Add `stratify=y` to the row split | 93.92% |
| Identity overlap across split | Exclude each whole identity during prediction | **76.66%** |

The first two fixes change the reported figure by just 0.25 and 0.51 percentage points. Removing identity overlap causes a 16.76 percentage point decrease relative to the original holdout, revealing the substantive leakage.

## Why group-based leave-one-out?

The dataset includes 900 `(date_of_birth, citizenship)` groups. Of those, 540 contain multiple submissions. In the original 395-row test set, 308 rows share an identity group with the training set, and all 308 predictions are correct. Accuracy on the remaining 87 rows is 71.26%.

Ordinary `LeaveOneOut()` over rows is **not** a correction: it yields 95.94%, since sibling submissions remain in the training folds. `LeaveOneGroupOut()` instead holds out all rows with the same identity group together while generating exactly one out-of-fold prediction per application row. Identity fields define groups only; they never enter the model. Every training fold uses `StandardScaler` followed by `KNeighborsClassifier(n_neighbors=1)` on the same six numeric features.
